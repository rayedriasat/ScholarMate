# Product Overview

ScholarMate is an offline-first, Google-Drive-backed AI research workspace for managing PDFs and Markdown files.

## Core Value Proposition

- **User-owned storage**: All documents stored in user's Google Drive
- **Offline-first**: Full functionality without internet connection
- **AI-powered**: Semantic search with RAG over document library
- **Realtime collaboration**: Share and annotate documents with team members
- **Cost-free**: Built entirely on free-tier services

## Key Features

- Google OAuth authentication with Drive integration
- PDF viewing with annotations (highlight, underline, comments)
- Document scanning with hybrid OCR (DeepSeek online / Tesseract offline)
- PDF to Markdown conversion with structure preservation
- Markdown preview and editor with live rendering
- AI chat with RAG-based semantic search and citations
- Text-to-speech (read aloud) for PDFs
- Role-based sharing (Viewer/Editor) with public links
- Realtime collaboration with presence tracking
- Offline queue with auto-sync when online

## Target Users

Researchers, students, and knowledge workers who need to:
- Manage large PDF libraries
- Collaborate on research documents
- Search across their document collection using AI
- Work offline with automatic sync
- Own and control their data
